🧮 Python Calculator

A simple command-line calculator built with Python to perform common arithmetic operations. This project was created to practice Python fundamentals, user input, conditional statements, and arithmetic operators.

✨ Features

The calculator supports the following operations:

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- % Modulus
- ⚡ Power

🛠️ Technology

- Python 3

📚 Concepts Used

This project demonstrates the use of:

- Variables
- User Input
- Conditional Statements
- Arithmetic Operators
- Basic Error Handling
- Command-Line Interaction

▶️ How to Run

1. Make sure Python 3 is installed on your system.
2. Clone the repository:

git clone https://github.com/tayyabsb/python-calculator.git

3. Navigate to the project directory:

cd python-calculator

4. Run the program:

python calculator.py

💻 Example

===== SIMPLE PYTHON CALCULATOR =====
Enter first number: 25
Enter operator (+, -, *, /, %, **): *
Enter second number: 4

Result: 100.0
